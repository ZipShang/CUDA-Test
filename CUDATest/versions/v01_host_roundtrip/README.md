# v01 — Host Round-Trip Baseline

这是当前 GPU 图像融合的冻结基线版本。

## 设计

- 输入：16 张连续存储的 `CV_8UC1` 灰度图；
- 融合：两两归约，像素公式为 `(src1[i] + src2[i]) / 2`；
- GPU：每次融合均执行 2 次 H→D、1 次 `blendImage`、1 次 D→H；
- 正确性：`CUDATest.cpp` 的 CPU 参考实现使用同样的队列顺序和整数向下取整；
- 性能：GPU 流程运行 10 次，程序输出最后 5 次的平均墙钟时间。

## 已知性能数据

从 `CUDATestRepo.nsys-rep` 的第 6～10 轮统计：

| 指标 | 每轮平均 |
|---|---:|
| H→D | 34.923 ms |
| D→H | 16.684 ms |
| 数据传输合计 | 51.607 ms |
| 15 次 kernel 合计 | 1.605 ms |
| GPU 活动合计 | 53.212 ms |

数据传输占 GPU 活动时间约 96.98%，是下一版需要优先解决的问题。

## 局限

中间结果在每次两图融合后都回传到 CPU，下一轮又重新上传，导致 PCIe
传输远多于必要数量。v02 的目标是让中间结果始终驻留在 GPU。

本目录中的三个源码文件是冻结快照，不参与上级 Visual Studio 工程的编译。
